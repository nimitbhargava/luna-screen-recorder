# Contributing to Luna 🌙🐱

We'd like to try something a little different with this repo.

Given that coding agents write most underlying code now, **we prefer issues over pull requests — please do not open code PRs.**

### How to Propose Features & Changes
1. **Just open an issue.**
2. Keep it human-written and concise. Run your idea by us in the same informal way you would a coworker or friend over Slack.
3. **Please do not have AI artificially expand what you'd like to do into a formal 10-page PRD or proposal.** Just tell us what you want Luna to do, why you need it, and how you imagine it working.
4. If we're aligned on the direction, **we are happy to burn our own tokens** on the underlying implementation, tests, and packaging.

### Bug Reports
For bugs or rough edges, open an issue detailing:
- What happened (a screenshot or Luna screen recording is welcome!)
- Your macOS version
- Steps to reproduce

We appreciate this a lot, and will credit you in the release notes when the fix lands.

### Security
If you discover a security vulnerability, please report it privately to the maintainers rather than opening a public issue.
